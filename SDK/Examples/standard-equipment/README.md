# Ordinary apparel and melee author example

Experimental API1.2 example by SweetBriana. The numeric values are this example author's balance, not framework defaults. Use either this JSON declaration or StandardEquipmentConsumer; declaring both with the same identity is invalid.

The referenced OrdinaryVest and OrdinaryMace are existing content definitions in the separate original resolved-content test snapshot. This declaration does not create definitions. Fixed apparel requires independent mass, carried bulk, worn bulk and sharp/blunt/heat armour values; standalone melee requires mass/bulk plus damage, cooldown and both penetration values for every ordinary tool.

Vanilla sharp/blunt fractions are not physical CE armour baselines. The manager keeps unavailable original units separate from the author proposal. Custom shield/resource components, apparel material armour and special tool attacks require other audited adapters. The API1.2 native qualification is still in progress; do not deploy this example to a normal colony.
